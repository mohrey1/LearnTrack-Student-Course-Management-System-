LearnTrack is a console-based Java application designed to manage students, courses, and enrollments for an educational platform.
The project demonstrates core Object-Oriented Programming (OOP) concepts and clean application design using Java.

Features
Student Management------------
Add new students
View all students
Search student by ID
Deactivate a student (soft delete)

Course Management---------------
Add new courses
View all courses
Activate / Deactivate courses

Enrollment Management-----------
Enroll a student into a course
View enrollments for a student
Update enrollment status (ACTIVE / COMPLETED / CANCELLED)

Exception Handling-------------
Custom EntityNotFoundException
Safe input handling using try-catch
User-friendly error messages (no crashes)
